## Why
- 当前用户提交图像生成任务后无法撤回，错误参数会占用队列资源并延迟其他任务
- 提供取消能力可提升资源利用率，并让用户在发现错误时快速重试

## What Changes
- 后端新增任务取消 API 和服务逻辑：当任务处于队列或执行中时进行撤销，并同步 Redis 状态
- WebSocket 广播任务取消事件，前端及时更新任务列表和提示
- 前端 UI 提供“取消任务”操作，包含状态禁用和确认交互

## Impact
- API surface 新增，需要更新 OpenAPI/客户端调用层
- 任务队列逻辑需处理取消场景，确保不会导致悬挂的工作线程
- 需要追加单元测试和端到端测试覆盖取消流程
